# 🛡️ نظام الرقابة الأبوية الذكية

نظام رقابة أبوية قائم على متصفح الويب يتيح لولي الأمر:
- **عرض شاشة جهاز الابن لحظياً** (بث مباشر عبر WebRTC)
- **إرسال رسائل تنبيه فورية** تظهر بملء الشاشة
- **قفل وفتح شاشة الابن** عن بُعد
- **إنهاء الجلسة** بشكل كامل

> ⚠️ **ملاحظة:** النظام يقوم على مشاركة شاشة طوعية. عند بدء الجلسة، يظهر للابن تنبيه "مشاركة الشاشة" في المتصفح (وهذا إجراء أمني لا يمكن تخطيه). لا يمكن استخدام النظام للتجسس الخفي.

---

## 📁 هيكل المشروع

```
الرقابة الابوية/
├── package.json          # ملف إعدادات المشروع
├── server.js             # خادم Node.js (Express + Socket.IO)
├── public/
│   ├── index.html        # الصفحة الرئيسية
│   ├── parent.html       # لوحة تحكم ولي الأمر
│   └── child.html        # صفحة الابن (مشاركة الشاشة)
└── README.md             # هذا الملف
```

## 🧠 كيف يعمل الاتصال؟

- **الخادم (Node.js + Socket.IO):** يدير الجلسات ويُمرّر إشارات WebRTC (signaling) فقط.
- **الاتصال نفسه (الشاشة والأوامر):** يتم مباشرةً بين جهازي الأب والابن عبر WebRTC (P2P).
- **الخصوصية:** لا يمرّ أي محتوى شاشة عبر الخادم — الصورة تنتقل مباشرة بين الجهازين.

## 🚀 طريقة الاستخدام

### 1️⃣ تشغيل الخادم محلياً

```bash
# تأكد من وجود Node.js (v16+)
node --version

# انتقل إلى مجلد المشروع
cd "e:/flutterpro/برامج اختراق/الرقابة الابوية"

# ثبّت الحزم المطلوبة (مرة واحدة فقط)
npm install

# شغّل الخادم
npm start
```

بعد التشغيل، افتح المتصفح على الرابط: **http://localhost:3000**

### 2️⃣ طريقة عمل الجلسة

| الخطوة | ولي الأمر (Parent) | الابن (Child) |
|--------|-------------------|---------------|
| 1 | افتح **http://localhost:3000** ← اختر "الدخول كولي أمر" | - |
| 2 | اضغط **"إنشاء جلسة جديدة"** | - |
| 3 | سيظهر رابط. انسخه أو أرسله عبر واتساب لابنك | يفتح الرابط في متصفحه |
| 4 | انتظر ظهور شاشة الابن في لوحة التحكم | يدخل رمز الجلسة تلقائياً أو يضغط **"بدء الجلسة"** |
| 5 | تظهر شاشة الابن لحظياً ← استخدم أزرار التحكم | يختار الشاشة/النافذة للمشاركة ← يضغط "مشاركة" |
| 6 | - | تظهر له نافذة مشاركة الشاشة (اختيار شاشة/نافذة/تبويب) |

### 3️⃣ أزرار التحكم (لوحة ولي الأمر)

| الزر | الوظيفة |
|------|---------|
| 💬 رسالة تنبيه | إرسال رسالة تحذيرية عامة |
| 🔒 قفل الشاشة | قفل شاشة الابن بالكامل (يظهر له overlay أحمر) |
| 🔓 فتح الشاشة | فتح الشاشة المقفولة |
| 📱 واتساب | فتح واتساب ويب مع الرابط مُعدّ للإرسال |
| 📋 نسخ | نسخ رابط الدعوة |
| ⏹ إنهاء الجلسة | إنهاء الجلسة بالكامل |

## ☁️ الاستضافة المجانية (للوصول عبر الإنترنت)

### الخيار 1: Render.com (الأسهل)

1. أنشئ حساباً على [render.com](https://render.com)
2. اربط GitHub/ GitLab أو ارفع الكود مباشرة
3. اختر **New Web Service**
4. الإعدادات:
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Auto-Deploy:** yes
5. بعد النشر، سيظهر رابط مثل `https://your-app.onrender.com`

### الخيار 2: Railway.app (مجاني)

1. حساب على [railway.app](https://railway.app)
2. New Project → Deploy from GitHub repo
3. Build: `npm install`
4. Start: `npm start`
5. ستحصل على رابط مباشر

### الخيار 3: Vercel (مع تعديل بسيط)

Vercel للمشاريع الثابتة بشكل أساسي، لكن يمكنك استخدامه مع وظيفة Serverless:

```bash
npm i -g vercel
vercel
```

(ملاحظة: قد تحتاج تعديلات إضافية لـ Vercel للتعامل مع Socket.IO و PeerJS)

## 🛡️ الخصوصية والأمان

- **البيانات لا تُخزّن:** جميع الصور والفيديو تنتقل مباشرة بين الجهازين (P2P) عبر WebRTC
- الخادم فقط يُدير الإشارات (signaling) ولا يرى محتوى الشاشة
- أي جلسة تنتهي صلاحيتها بعد 24 ساعة
- اتصال مشفّر (DTLS/SRTP) بين الطرفين
